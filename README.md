## Getting Started

### Prerequisites

- Git installed on your computer
- A GitHub account
- A terminal such as Ubuntu Terminal

### Clone the Repository

To download this repository to your computer, run:

```bash
git clone https://github.com/Goniswamy/codeshack-goniswamy.git
cd codeshack-goniswamy
```

### Explore the Handbook

- Read `git-notes.md` to learn common Git commands.
- Practise the commands in a test repository before using them in important projects.
- Use `git status` to check your working directory.
- Use `git log --oneline` to review your commit history.
